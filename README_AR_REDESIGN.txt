Deutsch – إعادة تصميم واجهة المنصة
====================================

ما تم تحديثه
------------
1) واجهة الطالب أصبحت عربية RTL ومتجاوبة مع الهاتف والكمبيوتر.
2) تصميم لوحة "اليوم" ببطاقة الدرس التالي، هدف اليوم، خطة المهام، وإحصائيات حقيقية من نتائج الحساب.
3) شريط تنقل سفلي ثابت ومتجاوب: اليوم، تعلّم، تكلّم، الجلسات، تقدّمي، المجتمع، بأيقونات SVG واضحة وحالة نشطة زرقاء مع خط أصفر.
4) إصلاح قاعدة CSS كانت تمنع تطبيق تنسيق شريط التنقل، لذلك لن تظهر الأقسام كأزرار HTML افتراضية في أعلى الصفحة.
5) صفحة التعلّم تعرض خارطة الطريق A1–C2، مع فتح A1 لأنه المستوى الذي يحتوي على محتوى فعلي في المشروع الحالي.
6) صفحة التكلّم تحتوي سيناريوهات تدريب، كتابة، نطق صوتي عبر المتصفح، واستماع إلى الجمل.
7) صفحة الجلسات تعرض بطاقات جلسات نموذجية مع تسجيل اهتمام محلي.
8) صفحة المجتمع تعرض الغرف حسب المستوى مع لوحة رسائل محلية.
9) صفحة الدخول مترجمة للعربية، مع زر "معاينة تجريبية" لتجربة التصميم دون حساب.
10) تم الحفاظ على الدروس العشرة الموجودة، ملفات الصوت، الاختبارات، تقارير التقدم، لوحة الإدارة، وربط Firebase الموجود.

طريقة التشغيل
-------------
1) فك ضغط Deutsch_A1_Plattform_Redesign.zip.
2) افتح المجلد Deutsch_A1_Plattform 6.
3) شغّل خادماً محلياً من داخل المجلد:
   python -m http.server 8000
4) افتح:
   http://localhost:8000

للتجربة دون حساب
----------------
في صفحة تسجيل الدخول اضغط:
"استكشف التصميم · معاينة تجريبية"

وضع المعاينة لا يحتاج Firebase Authentication، ولا يرسل بيانات إلى قاعدة البيانات. يمكنك التنقل بين الصفحات وتجربة المحادثة والغرف والمهام.

ملاحظات مهمة قبل الإطلاق الفعلي
-------------------------------
- المحتوى التعليمي الفعلي الموجود في المشروع هو A1 (10 دروس). A2 وB1 وB2 وC1 وC2 معروضة في خارطة الطريق كأقسام قادمة، ولم أضع محتوى وهمياً مكان الدروس غير الموجودة.
- "المدرّب الذكي" الحالي نموذج محلي تجريبي بقواعد تصحيح محدودة، مع استعمال Web Speech API للنطق/الإملاء عند دعم المتصفح. ليس متصلاً بعد بنموذج ذكاء اصطناعي حقيقي. لربط AI يجب إضافة Cloud Function أو خادم وسيط وحفظ مفتاح API في الخادم، وليس داخل JavaScript في المتصفح.
- الجلسات حالياً بطاقات نموذجية وتسجيل الاهتمام محلي على نفس الجهاز؛ لا يوجد اتصال فيديو أو حجز مركزي حقيقي بعد. يلزم دمج مزود WebRTC/Video أو خدمة جلسات.
- رسائل المجتمع حالياً تحفظ محلياً في المتصفح فقط ولا تصل إلى متعلمين آخرين. قبل تفعيلها لجميع المستخدمين يجب إضافة مسارات قاعدة بيانات وصلاحيات Firebase Rules تمنع قراءة رسائل الغرف غير المصرح بها وتتحقق من هوية المرسل.
- لم أغيّر Firebase Rules أو إعدادات المشروع، ولم أرفع أي شيء إلى Firebase. الوظائف الحالية للدخول ولوحة الإدارة تبقى كما هي.
- لم يتم إنشاء محتوى A2–C2 أو اختبارات تحديد مستوى جديدة؛ الواجهة تُظهرها كخارطة طريق فقط.

التحقق
------
- تم فحص صياغة JavaScript بواسطة Node.js (node --check).
- ملفات الدروس والصوت والصور الأصلية بقيت ضمن المشروع.


التحديث الإضافي – توحيد الواجهة ومحادثات كل درس
------------------------------------------------
1) تم تحويل واجهة الطالب إلى إطار موحّد بعرض مناسب للهاتف على الشاشات الكبيرة، مع خلفية زرقاء/بنفسجية وإطار داكن وشاشة داخلية فاتحة.
2) تم توحيد رأس الصفحات وشريط التنقل السفلي ليبقيا بنفس المكان والهوية البصرية في جميع أقسام الطالب.
3) تم ضبط بطاقات المستويات والدروس ومحتوى الصفحات القديمة لتظهر داخل نفس إطار التطبيق بدلاً من صفحات عريضة بتصميم مختلف.
4) قسم "تكلّم" أصبح مرتبطاً بعشرة دروس A1: التعارف، العائلة، السكن، الطعام والشراب، الروتين اليومي، الهوايات، التسوق، العمل، المدينة والمواصلات، والصحة والمواعيد.
5) يمكن تغيير الدرس مباشرة من قسم "تكلّم"، وتظهر أسئلة ومفردات وجمل نموذجية مناسبة لكل درس.
6) أضيفت 15 طريقة تدريب في قسم "تكلّم"؛ كل بطاقة تغيّر نوع التمرين أو توجّه المحادثة إلى نشاط مناسب.
7) أضيف زر "محادثة الدرس" داخل صفحة كل درس لفتح تدريب الكلام على نفس موضوع الدرس.
8) تم الحفاظ على وضوح حدود النسخة التجريبية: ردود المدرّب والتصحيح قواعد محلية محدودة، وليست نموذج AI متصلاً بالخادم. الإملاء الصوتي يعتمد على دعم المتصفح والميكروفون.

التحقق الإضافي
---------------
- تم فحص JavaScript بواسطة node --check.
- تم تحليل CSS والتأكد من عدم وجود أخطاء تركيبية ظاهرة.
- لم يتم تغيير إعدادات Firebase أو رفع ملفات إلى الخادم.
