# Deutsch A1 — إضافة «نافس نفسك»

تمت إضافة وضع جديد داخل قسم **المنافسة** باسم **نافس نفسك**. يقدر التلميذ يدير اختبار بوحده، يشوف النتيجة والنسبة والأجوبة الصحيحة، يعاود نفس التحدي، ويقارن محاولته بأفضل نتيجة شخصية محفوظة في حسابه.

## الملفات اللي خاصها تتبدّل فالمشروع

- `index.html`
- `js/app.js`
- `css/style.css`
- `supabase/functions/competition/index.ts` — كود Edge Function المحدّث

خلي باقي ملفات المشروع كما هي، خصوصاً ملفات إعداد Firebase وSupabase وصفحات الاختبارات.

## خطوات التفعيل

1. افتح **Supabase → SQL Editor**.
2. نفّذ محتوى الملف:
   `supabase/migrations/20261123_add_self_competition.sql`
3. افتح **Supabase → Edge Functions → competition → Code**، واستبدل الكود بمحتوى:
   `supabase/functions/competition/index.ts`
4. انشر Edge Function من جديد.
5. عوّض ملفات الواجهة الثلاثة (`index.html` و`js/app.js` و`css/style.css`) بالنسخ الموجودة هنا، ثم ارفع الموقع بالطريقة المعتادة.
6. سجّل الدخول بحساب تلميذ، افتح قسم **المنافسة**، واختار **نافس نفسك**.

> مهم: خاص تشغيل ملف SQL قبل نشر واستعمال الخاصية، حيث كينشئ جداول خاصة بحفظ المحاولات وأفضل النتائج. نقاط المنافسة الجماعية والغرف الحالية بقات بنفس النظام القديم.

## كيفاش كتتحسب النتيجة؟

- كل جواب صحيح = 10 نقاط.
- النتيجة كتتحفظ حسب الدروس وأنواع التمارين المختارة.
- أفضل نتيجة وعدد المحاولات وآخر نتيجة كيبقاو محفوظين فقاعدة البيانات ومرتبطين بحساب التلميذ.
- أجوبة الاختبار الصحيحة كتبقى فالخادم، وما كتتبعتش للمتصفح.
