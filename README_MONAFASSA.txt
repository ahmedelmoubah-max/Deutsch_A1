MONAFASSA — إصلاح الدخول للتمارين + تنسيق النافذة
نسخة 17-11-2026 — auto-start fix 4
=============================================

المشكل اللي بان فالصورتين:
1) ملي كيدخلو جوج لاعبين فمنافسة 1 ضد 1، كتكون الغرفة عامرة
   ولكن المنافسة كانت كتبقى فحالة الانتظار حتى يضغط صاحب الغرفة «ابدأ».
2) نافذة رمز الغرفة كانت كتبان بلا تنسيق لأن CSS ديالها ناقص.

شنو تصلّح:
- فمنافسة 1 ضد 1، بداية تلقائية ملي يدخل اللاعب الثاني:
  (أ) الخادم Supabase كيبدا الجولة من بعد انضمام الثاني.
  (ب) حتى متصفح صاحب الغرفة فيه fallback إلى مازال الخادم قديم.
- المحافظة على البداية اليدوية فمنافسة المجموعة (GROUP).
- إظهار رمز الغرفة مباشرة داخل صفحة الغرفة مع «نسخ» و«مشاركة»،
  بلا popup صغير يحجب الصفحة. نافذة أخطاء الإنشاء ولات منسّقة.
- إصلاح سباق Start من المتصفح والخادم، بحيث تحديث الغرفة ينجح
  حتى إلا بدأها الخادم فداك الوقت.
- الاحتفاظ بباقي التمارين والأسئلة والخصائص من النسخة السابقة.
- تغيير رقم نسخة ملفات CSS/JS لإجبار المتصفح يحمّل التغييرات.

طريقة النشر (ضروري):
1) بدل ملفات موقعك بالملفات داخل ZIP (داخل جذر الموقع، ماشي ملف ZIP بلا فك).
   خصوصاً: index.html / js/app.js / css/style.css
2) باش تخدم البداية التلقائية من الخادم، عاود نشر:
   supabase/functions/competition/index.ts
   باستعمال Supabase CLI، من داخل مجلد المشروع:

   supabase login
   supabase link --project-ref nqwaaapraiwbkagfssqo
   supabase functions deploy competition --no-verify-jwt

   ملاحظة مهمة: --no-verify-jwt ضرورية لأن التطبيق يستعمل Firebase ID token
   وEdge Function كيتحقق من التوكن ديال Firebase بنفسه.
   ما تبدّلش service_role أو secrets الحالية.
3) فالمتصفح ديال جوج اللاعبين، دير Ctrl + Shift + R، أو مسح كاش الموقع.
4) صايب غرفة جديدة، اختار «1 ضد 1»، وصيفط الرمز للاعب الثاني.
   أول ما يدخل الثاني، كيبدأ الامتحان بلا ما تضغط Start.
   فالمجموعة (GROUP) صاحب الغرفة هو اللي كيضغط «ابدأ المنافسة».

إذا لم تتم إعادة نشر Edge Function:
- متصفح صاحب الغرفة غالباً يقدر يبدأ الجولة تلقائياً بمجرد يشوف 2/2،
  ولكن البداية على الخادم أكثر ثباتاً (خصوصاً إذا صاحب الغرفة سكر الصفحة).
- من الأفضل إعادة نشر function وإنشاء غرفة جديدة للتجربة.

اختبارات محلية ناجحة:
- جوج لاعبين 1 ضد 1 -> البداية التلقائية (frontend + backend simulations).
- لاعب واحد -> الانتظار الطبيعي.
- GROUP -> البداية اليدوية.
- Race condition -> ما كتفشلش عملية الانضمام.
- Syntax ديال JavaScript وTypeScript بلا أخطاء.

تنبيه: الاختبارات محلية باستعمال بيانات اتصال وهمية؛ ما تمش الاتصال بحسابك
الحقيقي فـ Supabase ولا تجربة نهائية مباشرة مع حسابات التلاميذ ديالك.
